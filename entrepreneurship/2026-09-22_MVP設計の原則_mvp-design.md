# MVP設計の原則：何を作らないか、最小限の検証方法

## 概要

MVPは「最小限の機能を持つプロダクト」ではなく、「最小のコストで最大の学びを得るための手段」。個人開発者が陥りがちな罠は、ユーザーの反応を見る前に機能を作りすぎること。MVP設計の本質は「何を作るか」より「何を作らないか」にある。リソースが限られているソロファウンダーにとって、検証速度こそが最大の競争優位になる。

---

## 核となる考え方

- **MVPの目的は販売ではなく学習** — 売上より「誰の、何の課題を、どう解くか」の仮説を検証することが先
- **リスクの種類を分ける**
  - 需要リスク：そもそもユーザーはこれを求めているか？
  - ユーザビリティリスク：使えるか？
  - 実現可能性リスク：自分に作れるか？
  - 収益リスク：お金を払ってもらえるか？
- **最初に検証すべきは需要リスク** — 技術的に作れるかより、「誰かが欲しいと思うか」を先に確かめる
- **MVPの段階**
  1. Fake MVP（Wizard of Oz）：手動で動かして反応を見る
  2. Landing page MVP：機能を作る前にLPで予約・登録を集める
  3. Concierge MVP：自動化せず人力でサービスを提供する
  4. Functional MVP：最低限の機能だけ実装

## 実践フレームワーク・ステップ

### ステップ1：検証したい仮説を1文で書く
```
「[ターゲット] は [課題] を解決するために [ソリューション] に [対価] を支払う」
```
例：「フリーランスエンジニアは請求書作成の手間を減らすために、月500円のツールに課金する」

### ステップ2：最もリスクの高い仮説を特定する
- 「この仮説が間違っていたらプロダクトが成立しない」ものを1つ選ぶ
- それだけを検証するMVPを設計する

### ステップ3：MVP形式を選ぶ（コスト順）

| 形式 | コスト | 検証できること |
|------|--------|----------------|
| 顧客インタビュー | 0円・数時間 | 課題の存在と深刻さ |
| Googleフォーム | 0円・数時間 | 機能への需要 |
| Notion/概念LP | 0円・1日 | ランディング訴求 |
| Carrd LP + 決済 | 月$19 + 1日 | 支払い意欲 |
| Nocode（Glide等） | 月$0〜 + 3日 | 操作性 |
| 手動+スプレッドシート | ほぼ0円 | プロセス全体 |

### ステップ4：成功基準を先に決める
- 「Xが達成されたら仮説は正しい」と数値で定める
- 例：「LPに100人来て、10人がメール登録したらニーズあり」

### ステップ5：制限時間を設ける
- MVPに使う時間を**最大1〜2週間**に制限する
- 期限を超えても検証できない場合は仮説を変える

## 成功・失敗の事例

### 成功例：Zapierの初期MVP
- ウェブフックの繋ぎこみを手動で行い、まず需要を確認
- エンジニア創業者がコードを書く前にユーザーを獲得

### 成功例：DropboxのExplainer Video MVP
- プロダクトが存在しない状態でデモ動画を公開 → 一晩で7万5千人が登録
- 「作る価値がある」を確認してから開発開始

### 失敗例（個人開発でよくあるパターン）
- 6ヶ月かけてフル機能を実装 → ローンチして誰も使わない
- 「自分が使いたいから作った」だけで他のユーザーの需要確認ゼロ
- LP訴求を確認せずAppStoreにリリースしてインストール数ゼロ

---

## アンチパターン

- **「もう少し機能を足してからリリース」地獄** — リリースを遅らせるほど検証が遅れる
- **「作ること」が目的化する** — コードを書くことに満足してユーザー反応を見ない
- **成功基準なしにリリース** — 何が「成功」か決めないまま動かすと学びが得られない
- **自分だけのニーズで作る** — 開発者本人はユーザーと乖離していることが多い
- **完璧なUIを作ってから見せる** — Figmaのモックアップで十分な段階でコードを書く

1. **仮説を1文で書く** — 「[誰]が[何]のために[いくら]払う」という形式で、今考えているプロダクトの核心仮説を1文にまとめる
2. **Carrd/Notionで30分LP** — 機能を作る前にLPを作り、メール登録フォームを置いてSNSに投稿してみる（登録者ゼロなら需要確認が必要）
3. **「削除リスト」を作る** — 思い描く機能リストを全部書き出し、「これがなくても最初の検証はできる」ものを全部消す
