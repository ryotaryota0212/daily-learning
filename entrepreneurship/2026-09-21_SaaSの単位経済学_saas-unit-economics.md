# SaaSの単位経済学：LTV・CAC・Churn Rate・MRR/ARR

## 概要

SaaSビジネスにおける「単位経済学」とは、顧客1人あたりのコストと収益を数値化する思考法。感覚で「売れてる/売れてない」を判断するのでなく、数字でビジネスの健全性を確認できる。個人開発者がスケールすべきか・諦めるべきかを判断する唯一の基準にもなる。資金が尽きる前に自分のビジネスが健全かどうかを把握するために必須のスキル。

---

## 核となる考え方

**5つの基本指標**

- **MRR（Monthly Recurring Revenue）**：毎月の経常収益。`契約数 × 月額単価`
- **ARR（Annual Recurring Revenue）**：年間経常収益。`MRR × 12`
- **Churn Rate（解約率）**：1ヶ月で解約した顧客の割合。`解約数 ÷ 期初顧客数`
- **LTV（顧客生涯価値）**：1顧客が生涯に支払う金額。`月額単価 ÷ Churn Rate`
- **CAC（顧客獲得コスト）**：顧客1人を獲得するためのコスト。`広告・営業費用 ÷ 獲得顧客数`

**健全な事業の目安**

- `LTV / CAC ≥ 3`：これを下回ると成長に投資するほど赤字になる
- `Payback Period ≤ 12ヶ月`：CACを回収するまでの月数。長すぎるとキャッシュが枯渇する
- `月次Churn Rate ≤ 2%`：年間で約22%の離脱。3%超えると成長が打ち消される

## 実践フレームワーク・ステップ

### Step 1：MRRを計算する

```
例：月額980円 × 50人 = MRR 49,000円
```

- 新規MRR（New MRR）：今月の新規契約分
- 拡張MRR（Expansion MRR）：アップグレードによる増加分
- 解約MRR（Churned MRR）：解約による減少分
- **Net New MRR = New MRR + Expansion MRR - Churned MRR**

### Step 2：Churn Rateを正確に把握する

```
期初顧客数100人、今月解約3人 → Churn Rate = 3%
LTV = 980円 ÷ 0.03 ≒ 32,666円
```

- 金額ベースのChurn（Revenue Churn）も重要：大口が抜けると数は少なくても痛い
- **Net Revenue Retention（NRR）**：アップグレードを含めた実質的な解約率。100%超えが理想

### Step 3：CACを計算する

```
先月の広告費30,000円 + 自分の営業時間（時給換算10,000円）
÷ 新規獲得10人 = CAC 4,000円
```

- 個人開発では「自分の時間」をコストとして必ず含める
- 無料トライアルからの転換率も分母に影響する

### Step 4：LTV/CACで健全性チェック

```
LTV 32,666円 ÷ CAC 4,000円 = 8.2倍 → 健全
Payback Period = 4,000円 ÷ 980円 ≒ 4ヶ月 → 良好
```

## 成功・失敗の事例

**成功例：価格改定でLTVを2倍にしたソロファウンダー**

- 月額500円で運営していたツールをChurn Rate分析すると月3%（LTV ≒ 16,666円）
- 機能を絞り価格を1,500円に改定 → 解約率が2%に改善（LTV ≒ 75,000円）
- 顧客数は減ったがMRRと利益は増加。価格を上げると「真剣に使う層」が残る

**失敗例：MRRの伸びだけ見てCACを無視した拡大**

- SNS広告を毎月10万円投下しMRRが伸び続けた
- 計算するとChurn Rateが5%でLTV 19,600円、CAC 20,000円
- LTV < CAC の逆転現象。顧客が増えるほど赤字になる構造に気付かず資金が枯渇

---

## アンチパターン

- **MRRだけを見る**：解約が増えていても新規で補えているうちは気付かない。NRRも必ず見る
- **自分の時間をCACに含めない**：個人開発者が最も陥りやすい。時間はコストである
- **Churn Rateを「しょうがない」で放置する**：2%と5%では1年後のLTVが3倍以上変わる
- **コホート分析なしでChurnを語る**：全体平均ではなく「3ヶ月目に解約が増える」など時系列で見る必要がある
- **アクティブ率を無視してChurnだけ見る**：課金継続でも使ってない顧客は近い将来に解約する
