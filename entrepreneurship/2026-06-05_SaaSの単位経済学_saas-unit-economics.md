# SaaSの単位経済学：LTV・CAC・Churn・MRR/ARRを使いこなす

## 概要

SaaSを個人開発で作ったとき「売上は出てるのに儲かっている感じがしない」は単位経済学を知らないと起こる。
LTV・CACなどの指標を正しく読めると、どこに時間とお金を使うべきかが数字で見える。
投資家や共同創業者がいなくても、自分で意思決定できる唯一の武器が財務指標。

---

## 核となる考え方

- **MRR（Monthly Recurring Revenue）**：毎月確定している収益。サブスクの合計。
- **ARR**：MRR × 12。年間換算。投資家・比較に使う。
- **Churn Rate（解約率）**：月次解約率 = 月初ユーザー数 ÷ 解約数。5%超は危険信号。
- **LTV（顧客生涯価値）**：1顧客が生涯に払う総額。`LTV = ARPU ÷ Churn Rate`（ARPUは月次平均単価）
- **CAC（顧客獲得コスト）**：1人獲得にかかった総コスト。時間コストも含める。
- **LTV/CAC比率**：3以上が健全。1未満は赤字垂れ流し。
- **回収期間（Payback Period）**：CAC ÷ ARPU。12ヶ月以内が目安。

## 実践フレームワーク：個人開発者向けの計測ステップ

### Step 1：MRRを正しく分解する

| 種類 | 内容 |
|------|------|
| New MRR | 新規顧客からの収益 |
| Expansion MRR | アップセル・プランアップ |
| Churned MRR | 解約による損失（マイナス） |
| Net New MRR | 上記3つの合計 |

**Net New MRR がプラスなら成長中、マイナスなら縮小中。**

### Step 2：Churn Rateを月次で追う

```
月次Churn Rate = 解約ユーザー数 ÷ 月初ユーザー数 × 100
```

- 月2%以下：優秀（年間22%解約）
- 月5%：危険（年間46%解約）
- 月10%超：プロダクトに根本的な問題あり

### Step 3：LTVとCACを計算する

```
ARPU = MRR ÷ 総ユーザー数
LTV  = ARPU ÷ 月次Churn Rate

CAC  = (獲得に使った時間×時給換算 + 広告費) ÷ 獲得ユーザー数
```

個人開発は広告費ゼロでも「自分の時間」はコスト計上する。

### Step 4：判断に使う

| 状況 | 打ち手 |
|------|--------|
| LTV/CAC < 1 | 価格を上げるか、解約を減らす |
| Churn高い | オンボーディング改善、解約理由インタビュー |
| CAC高い | チャネルを絞る、コンテンツ流入を増やす |
| Payback長い | 前払い・年払いオプションを追加 |

## 事例

**成功例：Baremetrics（創業者1人）**
- MRR・LTV・Churnをリアルタイム可視化するSaaS
- 自社の指標を公開（オープンスタートアップ）してコンテンツマーケに転用
- Churn Rateを毎月追って解約メール自動化 → 月次Churn 4%→2%に改善

**失敗例：よくある個人開発**
- 有料転換率だけ見てChurnを無視
- 新規が入るが古いユーザーが出続ける「ザルバケツ」状態
- 気づいたときにはARRが伸びていないのに疲弊している

---

## アンチパターン

- **指標を全部同時に追う**：最初はMRRとChurn Rateの2つだけで十分
- **時間コストをCACに含めない**：SEOに100時間使ったなら時給換算で計上する
- **Churn理由を調べない**：解約ユーザーへの1通のメールが最も高ROIな調査
- **MRRを総収益と混同する**：買い切り売上はMRRではない
- **LTV計算にChurnを使わずざっくり計算**：不正確なLTVで広告を出すと赤字になる
