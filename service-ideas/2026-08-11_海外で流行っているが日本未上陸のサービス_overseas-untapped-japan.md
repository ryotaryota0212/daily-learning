## 具体的なサービスアイデア

### 1. 非デザイナー向けブランドキットSaaS（Looka / Brandmark の日本版）

**参考海外サービス**: Looka, Brandmark, Namecheap Logo Maker

**想定ユーザー**
- 開業したての個人事業主・フリーランス
- 小規模EC事業者
- 副業でショップを始める20〜40代

**収益モデル**
- ロゴ1点買い切り: ¥3,980〜¥9,800
- ブランドキット（ロゴ+名刺+SNSバナー）: ¥14,800
- 月額プラン（無制限修正）: ¥1,480/月

**技術スタック**
- Nuxt 3 + FastAPI + Neon（PostgreSQL）
- SVG生成: Python の svgwrite / Canvasベース
- 支払い: Stripe

**差別化ポイント**
- 和風デザインテンプレートを100種以上収録
- 「屋号」「印鑑風ロゴ」など日本特有ニーズに対応
- 英語UIが苦手なシニア層向けシンプルUX

**個人開発可否**: ◎ テンプレートさえ揃えれば1人でMVP可能

### 2. フリーランス向け自動請求書・契約書管理（HoneyBook の日本版）

**参考海外サービス**: HoneyBook, Bonsai, AND.CO

**想定ユーザー**
- デザイナー・エンジニア・ライター等のフリーランス
- 毎月複数クライアントへの請求が煩雑な人

**収益モデル**
- 無料プラン: 月3件まで
- プロ: ¥1,280/月（無制限 + 契約書テンプレート）
- チーム: ¥2,980/月（3名まで）

**技術スタック**
- Nuxt 3 + FastAPI + Neon
- PDF生成: WeasyPrint
- 電子署名: 自前実装 or DocuSign API

**差別化ポイント**
- インボイス制度・適格請求書フォーマットに完全対応
- クラウド会計（freee / マネーフォワード）との自動連携
- LINE通知でクライアントへの支払い督促を自動化

**個人開発可否**: ○ 法的要件のキャッチアップが必要だが技術的には1人で可能

### 3. 社内ナレッジ特化型AI検索（Guru / Slite の日本版）

**参考海外サービス**: Guru, Slite, Tettra

**想定ユーザー**
- 10〜100名規模のスタートアップ・中小企業
- Notionが普及したが「検索精度が低い」と感じているチーム

**収益モデル**
- 月額: ¥500/ユーザー（最小5名〜）
- エンタープライズ: 要見積もり

**技術スタック**
- Nuxt 3 + FastAPI + Neon
- ベクトル検索: pgvector（Neon対応）
- LLM: Claude API（claude-haiku-4-5でコスト最適化）

**差別化ポイント**
- Slack / Notion / Google Drive と連携して全社知識を一元検索
- 「なぜこの答えか」の根拠ドキュメントをリンク付きで提示
- 日本語形態素解析（MeCab）で検索精度を向上

**個人開発可否**: △ LLMコスト管理とデータセキュリティ対応がやや重いが挑戦可能
