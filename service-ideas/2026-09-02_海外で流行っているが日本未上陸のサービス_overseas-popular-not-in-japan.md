# 海外で流行っているが日本未上陸のサービス（2026年版）

作成日: 2026-09-02  
テーマ: 海外で実績のある、日本市場に未参入・未開拓のサービス領域

---

## 市場概要

- 米国・欧州で成功したSaaSが日本上陸まで平均2〜4年かかる
- 文化・言語・商習慣の壁が参入障壁となり、ローカル版への需要が高い
- 日本のSMBはDX遅れが顕著で、欧米で普及したツールの代替需要が大きい
- 2026年現在、AI統合型ツールは欧米が12〜18ヶ月先行しており追い風

---

## 具体的なサービスアイデア

### 1. AI議事録＋タスク自動化ツール（Fireflies.ai / Otter.ai の日本特化版）

**概要**: 会議を録音・文字起こしし、議事録・アクションアイテムを自動生成。日本語敬語・社内スラング対応。

- **想定ユーザー**: 中小企業の営業・プロジェクト管理チーム
- **収益モデル**: 月額1,980円/ユーザー（Freemium、月5時間まで無料）
- **技術スタック**: Nuxt + FastAPI + Neon + Whisper API + GPT-4o
- **差別化ポイント**: 日本語の敬語変換・社内固有名詞学習・Slack/kintone連携
- **個人開発可否**: ◎ 1人で3〜4週間でMVP可。音声処理はWhisper API委託で開発コスト低

---

### 2. SMB向け採用管理ATS（Greenhouse / Lever の軽量日本語版）

**概要**: 中小企業が使いやすいシンプルな採用管理システム。求人票作成〜面接スケジュール〜合否通知まで一元管理。

- **想定ユーザー**: 従業員10〜100名の採用担当者（専任不在が多い）
- **収益モデル**: 月額9,800円/社（採用枠3ポジションまで）、追加9,800円/3ポジション
- **技術スタック**: Nuxt + FastAPI + Neon + SendGrid + Google Calendar API
- **差別化ポイント**: 日本の雇用慣行に対応（内定承諾書・採用通知文テンプレ）、初期設定30分以内
- **個人開発可否**: ◎ 2週間でMVP。Neonでマルチテナント管理がシンプルに実現

---

### 3. 在庫・発注自動化ツール（Cin7 / Brightpearl の国内特化版）

**概要**: 実店舗＋ECを持つ中小小売・飲食が在庫をリアルタイム管理し、発注を自動化するSaaS。

- **想定ユーザー**: 実店舗とECショップを並行運営する個人事業主・中小小売業
- **収益モデル**: 月額14,800円（在庫拠点3ヶ所まで）、POSシステムAPI連携は+5,000円/月
- **技術スタック**: Nuxt + FastAPI + Neon + WebSocket（リアルタイム在庫同期）
- **差別化ポイント**: 楽天・Amazon・Shopify・Squareと即日連携。発注書のFAX自動送信対応（日本特有）
- **個人開発可否**: △ 外部API連携が多く4〜6週間必要。ただしコアの在庫管理は2週間で完成

---

### 4. コーチング・メンタリングマーケットプレイス（Coach.me / Clarity.fm の日本版）

**概要**: ビジネスコーチ・キャリアメンターと個人をマッチングし、ビデオ通話セッションを販売するプラットフォーム。

- **想定ユーザー**: キャリア転換・昇進を目指す20〜40代ビジネスパーソン
- **収益モデル**: セッション料金の20%手数料。月額サブスク（コーチ向け）8,000円/月
- **技術スタック**: Nuxt + FastAPI + Neon + Stripe Connect + Daily.co（ビデオ通話）
- **差別化ポイント**: コーチの実績・業界経歴の厳格審査制。セッション後AIによる振り返りレポート自動生成
- **個人開発可否**: ◯ マーケットプレイスの仕組みはStripe Connectで解決。4週間でMVP

### 総評
- **最推奨**: AI議事録ツール。海外競合が日本語対応を後回しにしている間に先行できる
- **狙い目**: 日本特有の商慣習（FAX、敬語、印鑑フロー）を取り込んだSaaSは模倣困難
- **リスク**: 欧米大手が本格的に日本語対応を進めた場合の価格競争に注意
