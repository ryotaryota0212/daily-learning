### 1. ポッドキャスト収益化支援SaaS（Supercast / Glow.fm の日本版）

**参照サービス:** Supercast（米）、Glow.fm（米）

**概要:**  
ポッドキャスターがリスナーから直接サブスクリプション収益を得られるプラットフォーム。海外では年間数百万円を稼ぐ個人ポッドキャスターが急増中だが、日本では Spotify / Voicy の広告モデル依存がほぼすべて。

**想定ユーザー:**
- フォロワー1,000〜10,000人規模の中規模ポッドキャスター
- 企業広告に頼らず直接収益化したいクリエイター

**収益モデル:**
- 収益の8〜10%を手数料として徴収（Supercaster方式）
- 月額基本料なし → 成功報酬型なので始めやすい

**技術スタック:**
- Nuxt 3 + FastAPI + Neon（PostgreSQL）
- 音声配信: Cloudflare R2 + HLS streaming
- 決済: Stripe（クレカ）＋ PayPay（日本向け追加）

**差別化ポイント:**
- 日本の確定申告に対応した収益レポート自動出力
- Voicy / stand.fm からのRSS移行ツールを同梱

**個人開発可能性:** ★★★★☆  
MVP（配信＋決済）は2〜3週間で構築可能。音声ストリーミングのインフラが最大の難所だが Cloudflare で解決できる。

### 2. 中小企業向け採用ブランディングSaaS（Teamtailor の日本版）

**参照サービス:** Teamtailor（スウェーデン、ARR $50M超）

**概要:**  
採用ページ（キャリアサイト）のノーコード作成＋応募者管理（ATS）を一体化したSaaS。海外では「採用サイトがない中小企業」向けに爆発的普及。日本では HRMOS / Recruit Jobsへの依存が強く、独自採用ブランディングのツールが空白地帯。

**想定ユーザー:**
- 従業員10〜100人のスタートアップ・中小企業の人事担当者
- 採用ページを Wantedly 以外で持ちたいが開発リソースがない企業

**収益モデル:**
- 月額 ¥19,800〜¥49,800（企業規模別ティア）
- 年払い20%割引
- 100社獲得でMRR約200万円

**技術スタック:**
- Nuxt 3（採用ページビルダーUI）+ FastAPI + Neon
- ページ公開: Vercel Edge / Cloudflare Pages（カスタムドメイン対応）
- 応募者管理: 自前ATS（シンプルなKanbanボード）

**差別化ポイント:**
- Wantedly との併用を想定したリンク導線テンプレート
- 日本語の採用コピーをAIが自動生成（JD → キャリアページ文章）
- Indeed / Green へのクロスポスト機能

**個人開発可能性:** ★★★☆☆  
ページビルダーのUI設計が工数の大半。ドラッグ&ドロップ系はライブラリ（Vue Draggable等）で短縮可能。3〜4週間でMVPは出せるが、営業が最大ボトルネック。

### 3. フリーランス向け自動請求・税務SaaS（Bonsai / Honeybook の日本版）

**参照サービス:** Bonsai（米、ARR $20M+）、HoneyBook（米）

**概要:**  
契約書作成→請求書発行→入金追跡→経費管理→確定申告データ出力をワンストップで行うフリーランス専用SaaS。日本では freee / マネーフォワードがあるが「フリーランスの業務フロー全体」にフォーカスしたプロダクトは薄い。

**想定ユーザー:**
- デザイナー・エンジニア・ライター等のフリーランス（副業含む）
- 月5〜20件の案件をこなす個人

**収益モデル:**
- 月額 ¥1,480（個人プラン）/ ¥2,980（チームプラン）
- 年払い限定で ¥9,800/年のスタータープランも用意
- フリーランス人口180万人のうち1%獲得 → MRR 2,660万円

**技術スタック:**
- Nuxt 3 + FastAPI + Neon
- PDF生成: WeasyPrint（Python）でインボイス制度対応の請求書
- 電子署名: クラウドサイン API 連携（オプション）

**差別化ポイント:**
- **インボイス制度（適格請求書）に完全対応**した請求書テンプレート（これだけで差別化になる）
- 案件ごとのP/L（売上・経費・利益）を自動計算
- 「確定申告に必要なデータをCSV/XMLで出力」機能

**個人開発可能性:** ★★★★★  
既存サービスが多い分、API・ライブラリが充実。PDF生成・請求書管理は実装パターンが確立されており、1週間でコアMVPを作れる。インボイス対応の法的要件調査が最大の作業。
