# 海外で流行っているが日本未上陸のサービス

**作成日**: 2026-07-18  
**テーマ**: 海外トレンド × 日本市場の空白地帯

---

## 市場概要

- 日本はデジタル化の遅れと「国産志向」から、海外で確立したSaaSが参入しにくい土壌
- 一方で言語・文化の壁が参入障壁となり、先行者優位を得やすい
- 海外実績をそのまま翻訳・日本語化するだけでPMFを短縮できるケースが多い
- 特にBtoB領域で「機能は知っているが日本語対応がない」という需要が慢性的に存在する

---

## 具体的なサービスアイデア

### 1. カレンダー連携型 1on1管理ツール「1on1ログ」

**参照サービス**: Lattice（米）、Culture Amp（豪）の1on1機能

**想定ユーザー**
- 中小企業の管理職・人事担当者（10〜300名規模）
- リモートワーク普及で1on1を始めたが記録・追跡できていないチーム

**課題（国内の現状）**
- Latticeは高額で中小企業向けではない（年間数百万円〜）
- Notionや手書きで管理しており継続性がない
- 上司が部下との会話内容を振り返れず成長支援が形骸化

**機能**
- Google Calendar / Outlook連携で1on1を自動検出
- 事前アジェンダ・会話メモ・アクションアイテムを一画面で管理
- AIが前回からの変化・未完了タスクをサマリー

**収益モデル**
- フリーミアム（2名まで無料）→ ¥500/人/月〜
- 10名チームで月5,000円、50名で25,000円

**技術スタック**
- Nuxt3 + FastAPI + Neon（PostgreSQL）
- Google Calendar API / Microsoft Graph API
- OpenAI API（サマリー生成）

**差別化ポイント**
- 完全日本語UI・日本のHR慣習（等級制度・目標管理）に対応
- 軽量SaaS、HRMSと連携しなくても単体で使える

**個人開発可能性**: ★★★★☆（4/5）
- MVP（カレンダー連携 + メモ）は2〜3週間で実装可能
- HRデータを扱うため信頼性の担保が肝心だが、小規模からスタートしやすい

---

### 2. 工数・請求書統合管理「TimeSync」

**参照サービス**: Harvest（米）、Toggl Track（フィンランド）

**想定ユーザー**
- フリーランスエンジニア・デザイナー、小規模制作会社
- 複数クライアントを抱えて請求書作成が月末に手間になっている人

**課題（国内の現状）**
- Harvestは英語UIで日本の消費税・インボイス制度未対応
- Toggl Trackは時間追跡のみで請求書作成が別ツール
- freee/マネーフォワードは機能過多で工数追跡に特化していない

**機能**
- タイマー一発起動で作業時間を記録（プロジェクト・タスク単位）
- 月次集計から適格請求書（インボイス）を自動生成
- GitHub連携でコミット時刻から作業時間を推定

**収益モデル**
- 個人プラン: ¥480/月
- チームプラン: ¥980/人/月（3名〜）
- インボイス出力を有料機能としてフリーミアム入口を設ける

**技術スタック**
- Nuxt3 + FastAPI + Neon
- GitHub Webhooks（コミット連携）
- PDFkit（請求書生成）

**差別化ポイント**
- インボイス制度・消費税区分に完全対応した日本特化設計
- GitHub連携で「作業した証拠」としても活用可能

**個人開発可能性**: ★★★★★（5/5）
- 技術的難易度が低く、日本の税制対応という強固な差別化がある
- フリーランス向けなのでSNS（X/note）での口コミが広がりやすい

---

### 3. 採用候補者向けメッセージ自動化「OutreachAI」

**参照サービス**: Gem（米）、Beamery（英）

**想定ユーザー**
- スタートアップの採用担当者・人事（3〜50名規模）
- ヘッドハンター・人材紹介会社のRA（リクルーティングアドバイザー）

**課題（国内の現状）**
- Gemは完全英語UI・LinkedIn中心で日本市場に不向き
- Wantedly / Green からのスカウト文を毎回手書きしている
- 候補者ごとにカスタマイズしたいが時間がない

**機能**
- 候補者プロフィール（Wantedly / LinkedIn / GitHub）を読み込みAIがスカウト文を生成
- テンプレート変数とAI補完を組み合わせたパーソナライズ送信
- 返信率・開封率をトラッキングしてA/Bテスト

**収益モデル**
- 月30通まで無料 → ¥9,800/月（無制限）
- 100名以上の大手向けにエンタープライズプラン（要問合せ）

**技術スタック**
- Nuxt3 + FastAPI + Neon
- Wantedly / LinkedIn API（または非公式スクレイピング）
- Claude API（Anthropic）でスカウト文生成

**差別化ポイント**
- 日本語スカウト文の品質に特化（丁寧語・ですます調の使い分け）
- Wantedlyなど日本主要媒体へのワンクリック送信

**個人開発可能性**: ★★★☆☆（3/5）
- APIの利用制限・規約リスクがあるため慎重な設計が必要
- 法人営業が必要になるケースも多く、個人開発だと信頼性の壁がある
- ただしAI文章生成部分は既存LLM APIで容易に実現できる

## 実現可能性の評価

| サービス | 技術難易度 | 市場規模 | 競合リスク | 個人開発適性 | 総合評価 |
|---------|-----------|---------|-----------|------------|---------|
| 1on1ログ | 中 | 中（HR-Tech） | 低〜中 | 高 | ★★★★☆ |
| TimeSync | 低 | 大（フリーランス全体） | 中 | 非常に高 | ★★★★★ |
| OutreachAI | 中高 | 中（採用市場） | 中 | 中 | ★★★☆☆ |

## まとめと推奨アクション

- **最速でリリースするなら**: TimeSync（インボイス対応工数管理）
  - 既存の海外ツールに「日本の税制対応」という強い差別化を持ち込める
  - フリーランスコミュニティ（X/note）との相性がよくグロースしやすい
- **中期的に大きくするなら**: 1on1ログ（HRテック）
  - HR-Tech市場は企業の組織課題と直結しており解約率が低い
  - エンタープライズへの横展開も視野に入る
- **注意点**: いずれも「なぜ今まで日本語版がなかったのか」を必ず検証すること
  - 規制・慣習・既存のワークフローが障壁になっている可能性を排除してからMVPを作る
