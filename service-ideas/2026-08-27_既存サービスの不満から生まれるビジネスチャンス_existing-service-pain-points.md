# 既存サービスの不満から生まれるビジネスチャンス

作成日: 2026-08-27  
テーマ: ユーザーの不満・フラストレーションを起点にしたサービス開発

---

## 市場概要

- 「不満起点のスタートアップ」はPMF（Product-Market Fit）を達成しやすい。なぜなら需要が既に証明されているから
- RedditのAITA・r/productivity・日本語圏のYahoo知恵袋などに蓄積された「○○サービスのここが嫌」が宝の山
- 競合が大きいほど不満ユーザーも多く、ニッチ特化で奪えるパイが大きい
- 2025〜2026年トレンド：大手SaaSの値上げ（Slack/Notion/Zoom等）が中小企業の乗り換えニーズを加速

### 不満が多いサービスカテゴリ（調査ベース）

| カテゴリ | 主な不満 | 乗り換え意向 |
|---------|---------|-----------|
| プロジェクト管理（Jira/Asana） | 複雑すぎる・高すぎる | 高 |
| ビデオ会議（Zoom/Meet） | 録画管理が面倒・AI要約の精度 | 中 |
| メールマーケ（Mailchimp等） | 価格体系が不透明・機能過多 | 高 |
| 経費精算（国内ツール） | UI古い・承認フロー硬直的 | 高 |
| 採用管理（ATS全般） | 候補者体験が悪い・連携複雑 | 中 |

## 具体的なサービスアイデア

### 1. **Jira難民向け軽量プロジェクト管理ツール「TaskLite JP」**

**背景・不満**
- Jiraは機能が多すぎて小規模チームには過剰
- セットアップに時間がかかり、管理者が必要
- 日本法人向けのサポートが弱い

**想定ユーザー**
- 5〜30名の国内スタートアップ・デザイン事務所・受託開発会社
- Jiraに疲れてNotionで代替しているが物足りないチーム

**収益モデル**
- フリーミアム：3プロジェクトまで無料
- $8/user/月（最低5名〜）：GitHub/Slack/Figma連携
- 年間一括払いで20%割引

**技術スタック**
- Nuxt 3 + FastAPI + Neon（PostgreSQL）
- リアルタイム更新：Supabase Realtime or Ably
- AI機能：タスク自動分類・工数見積もり（Claude API）

**差別化ポイント**
- 初期セットアップ5分以内（Jiraは平均2〜4時間）
- 日本語UI・日本のビジネス慣行（週次レポート形式など）に最適化
- 「Jiraからのインポート」機能で乗り換えコスト最小化

**個人開発可能性: ★★★★☆**
- MVPは1〜2週間で構築可能
- 最初はコア機能のみ（Kanban+担当者+締切）に絞れる

---

### 2. **Mailchimp代替・透明課金のメール配信SaaS「MailFlat」**

**背景・不満**
- Mailchimpは登録者数が増えると急激に料金が上がる（非線形課金）
- 退会者もカウントされる課金体系が不満
- 機能が多すぎてシンプルなメルマガ配信に不向き

**想定ユーザー**
- 個人クリエイター・ブロガー・小規模ECサイト運営者
- 登録者1,000〜10,000人のニュースレター運営者（国内）

**収益モデル**
- 完全フラット課金：¥2,000/月（配信数・登録者数無制限）
- プロプラン ¥5,000/月：A/Bテスト・カスタムドメイン・API
- 年払いで2ヶ月無料

**技術スタック**
- FastAPI + Celery（バルクメール送信キュー）
- AWS SES or SendGrid（配信インフラ）
- Neon PostgreSQL（購読者管理）
- Nuxt 3（ダッシュボード）

**差別化ポイント**
- 「退会者は翌月から課金対象外」を明記
- 料金計算シミュレーターをトップページに設置（競合との比較）
- 日本語テンプレート50種類以上

**個人開発可能性: ★★★☆☆**
- メール配信インフラの信頼性確保が難しい
- スパム対策・配信到達率の維持に専門知識が必要
- ただしSendGrid等に委託すれば3〜4週間でMVP可能

---

### 3. **国内経費精算ツール「Seisan Simple」（承認フロー特化）**

**背景・不満**
- 既存の経費精算ツール（楽楽精算・マネーフォワード等）は大企業向けで中小には過剰
- 承認フローが硬直的で「上長1人の承認」しかできない
- レシート撮影のOCR精度が低く手直しが多い

**想定ユーザー**
- 10〜100名の中小企業（製造業・士業・クリニック等）
- 経理担当が1〜2名しかいない会社

**収益モデル**
- ¥500/user/月（最低10名〜、つまり最低¥5,000/月）
- 会計ソフト連携オプション（freee/弥生）：¥2,000/月追加
- 導入支援パック：¥50,000（初回のみ）

**技術スタック**
- Nuxt 3 + FastAPI + Neon
- OCR：Google Document AI or Claude Vision API
- PDF生成：WeasyPrint
- 銀行振込連携：全銀フォーマット出力

**差別化ポイント**
- 承認フローを「誰でも5分で設定できるビジュアルエディタ」で定義
- 「仮払い → 清算」の2段階ワークフローを標準搭載
- 導入から初回承認まで1時間以内を保証（SLA）

**個人開発可能性: ★★★★☆**
- 機能を「経費申請・承認・CSV出力」に絞れば2週間でMVP
- 会計連携は後回しにできる
- BtoB固定課金なので収益が安定しやすい

---

### 4. **候補者体験を改善する採用管理ツール「Recruit Friendly」**

**背景・不満**
- 既存ATSは採用担当側の管理に最適化されており、候補者体験が悪い
- 応募後のステータス通知が遅い・不透明
- 面接日程調整のやりとりが煩雑（メール往復5〜6回）

**想定ユーザー**
- スタートアップ・中堅企業の採用担当（社内HR）
- 候補者体験を採用ブランディングの一環として重視する企業

**収益モデル**
- ¥30,000/月（求人数・採用担当者数無制限）
- エンタープライズ：¥80,000/月（カスタム採用ページ・API連携）

**技術スタック**
- Nuxt 3 + FastAPI + Neon
- カレンダー連携：Google Calendar API / Microsoft Graph
- 通知：SendGrid + LINE Notify（日本向け）
- AI：面接フィードバックの自動サマリー

**差別化ポイント**
- 候補者向けのリアルタイム選考ステータスページ（Uberの配達追跡UI風）
- 面接調整をAIが候補者と自動チャットで完結
- 不採用通知の文面をAIが個別最適化（紋切り型を排除）

**個人開発可能性: ★★★☆☆**
- カレンダー連携・通知の実装で3〜4週間
- 採用担当へのセールスが個人では難しい
- まず知人企業に無料提供してフィードバックを集める戦略が有効

## 実現可能性の評価

### 総合評価マトリクス

| アイデア | 開発難易度 | 市場規模 | 競合強度 | PMF速度 | 推奨度 |
|---------|----------|---------|---------|--------|-------|
| TaskLite JP | 中 | 中 | 高 | 速い | ★★★★☆ |
| MailFlat | 中〜高 | 中 | 中 | 中 | ★★★☆☆ |
| Seisan Simple | 中 | 大 | 中 | 速い | ★★★★★ |
| Recruit Friendly | 高 | 中 | 中 | 遅い | ★★★☆☆ |

### 個人開発者へのアドバイス

- **最初の1つを選ぶなら「Seisan Simple」**：BtoB固定課金で収益予測しやすく、MVP機能が明確
- **不満起点サービスの共通戦略**：競合のG2/Capterra/IT製品レビューの低評価コメントを読み込むことで本物の不満を特定できる
- **日本市場の強み**：海外ツールのローカライズが不十分な領域が多く、「日本語・日本の慣行に特化」だけで差別化になる
- **MVPは機能を3つに絞る**：不満解消に直結するコア機能のみ。課金は最初から入れる

### 参考：不満を見つけるリサーチ方法
