# 海外で流行っているが日本未上陸のサービス

作成日: 2026-09-05

---

## 市場概要

- 日本はSaaS・アプリ市場として世界3位規模だが、海外発プロダクトのローカライズ対応が遅れる傾向がある
- 言語・文化の壁、決済インフラの違い（クレカ普及率の差）、法規制が参入障壁になるケースが多い
- 逆に言えば「海外で実証済み・日本未上陸」は個人開発者にとって最も再現性の高いアイデアソースの一つ
- 2025〜2026年に海外で急伸し、日本でまだ本格展開されていないカテゴリが複数存在する

---

## 具体的なサービスアイデア

### 1. AIパーソナル財務コーチ（参考: Cleo / Monarch Money）

**概要**  
銀行口座・カード明細をAPIで連携し、AIが支出パターンを分析して毎週「財務アドバイス」を送るサービス。

**想定ユーザー**
- 20〜35歳の一人暮らし会社員
- 家計管理ツール（マネーフォワード等）は使っているが「アドバイスがない」と感じる層

**収益モデル**
- フリーミアム: 基本分析は無料、AIコーチング機能は月480円〜
- 提携金融商品（NISA口座・保険）のアフィリエイト

**技術スタック**
- Nuxt 3 (フロント) + FastAPI (バックエンド) + Neon (DB)
- 銀行連携: Plaid日本版 or マネーフォワードAPI
- LLM: Claude API（支出コメント生成）

**差別化ポイント**
- 国内競合（マネーフォワード・Zaim）はデータ集計止まり。「対話型コーチ」に特化
- LINEで週次レポートを送る日本ユーザー向けUX

**個人開発可能か**  
→ **可能（難易度: 中）** 銀行API連携が最大のハードル。マネーフォワードのAPIを使えば2〜3週間でMVP作成可能。

---

### 2. 職人・スモールビジネス向け見積もり＆請求書自動化（参考: Jobber / ServiceTitan）

**概要**  
水道・電気・内装工事など職人業向けの現場訪問→見積もり→請求→入金管理を一本化するモバイルファーストSaaS。

**想定ユーザー**
- 従業員5名以下の工務店・電気工事業者・リフォーム業者
- いまだにExcel・手書きで見積もりを作っている職人

**収益モデル**
- 月額5,000〜15,000円のSaaS
- 決済代行手数料（Square/Stripe連携）

**技術スタック**
- Nuxt 3 (PWA対応) + FastAPI + Neon
- PDF生成: WeasyPrint or Puppeteer
- 電子署名: DocuSign API or 国産代替

**差別化ポイント**
- Jobberは日本語・日本の税制（インボイス制度）に未対応
- スマホだけで完結するUI（PCを持たない職人向け）
- インボイス制度対応の自動仕訳

**個人開発可能か**  
→ **可能（難易度: 中〜高）** PDF・電子署名・決済の3要素が複雑だが、段階リリースなら1人でも可。初期はPDF生成のみに絞るとMVPは2週間以内。

---

### 3. 非同期チームビデオメモ（参考: Loom の競合: Vimeo / Scribe / Tella）

**概要**  
画面収録＋カメラ映像をワンクリックで録画→AI自動要約→チームへ共有するコミュニケーションツール。「会議を減らすため」の録画メモに特化。

**想定ユーザー**
- リモートワーク中のエンジニア・デザイナーチーム
- 「Slack文字だと伝わりにくいが、MTGを入れるほどでもない」案件が多い人

**収益モデル**
- 無料: 月10本・5分まで
- Pro月1,200円: 無制限 + AI要約 + 字幕自動生成
- Team月3,500円/人: 管理ダッシュボード + 閲覧統計

**技術スタック**
- Nuxt 3 + MediaRecorder API（録画）
- FastAPI + Neon + S3互換ストレージ（Cloudflare R2）
- Whisper API（文字起こし）+ Claude（要約）

**差別化ポイント**
- Loom（$8〜/月）は高く、日本語文字起こし精度が低い
- 日本語特化のWhisper fine-tuneモデルを使い精度向上
- Notion・Slack・Backlogへのワンクリック埋め込み

**個人開発可能か**  
→ **可能（難易度: 中）** MediaRecorder APIで録画→Whisper文字起こし→Claude要約の3ステップで本質機能が完結。1週間でMVP到達できる最も現実的なアイデア。

---

### 4. コーチング・メンタリングマーケットプレイス（参考: MentorCruise / Clarity.fm）

**概要**  
エンジニア・デザイナー・PMなどIT職種のメンターと学習者を繋ぐプラットフォーム。月額制のサブスク型メンタリングに特化。

**想定ユーザー**
- 転職・スキルアップを目指す20〜30代のITエンジニア
- 副業でメンタリングをしたいシニアエンジニア

**収益モデル**
- マーケットプレイス手数料: セッション料の15〜20%
- メンター掲載料: 月2,000円（被掲載プラン）

**技術スタック**
- Nuxt 3 + FastAPI + Neon
- ビデオ通話: Daily.co API or Whereby埋め込み
- 決済: Stripe Connect（マルチパーティ決済）

**差別化ポイント**
- MentorCruiseは英語のみ、Clarity.fmは日本語対応が弱い
- 「ITに限定」することでマッチング精度を高める
- AIによる「メンター推薦」（スキルギャップ自動診断）

**個人開発可能か**  
→ **可能（難易度: 中）** Stripe Connectのセットアップが複雑だが、最初はStripeの通常決済で代用できる。2〜3週間でMVP可能。

## 実現可能性の評価

| アイデア | MVP難易度 | 収益化速度 | 競合リスク | 個人開発推奨度 |
|---|---|---|---|---|
| AIパーソナル財務コーチ | 中 | 中（数ヶ月） | 中（マネーフォワードが参入リスク） | ★★★★☆ |
| 職人向け見積もりSaaS | 中〜高 | 速い（BtoB課金） | 低（ニッチ） | ★★★☆☆ |
| 非同期ビデオメモ | 低〜中 | 中 | 中（Loom強い） | ★★★★★ |
| メンタリングマーケット | 中 | 遅い（需給構築が必要） | 低 | ★★★☆☆ |

### 総評

- **最速でMVPを作るなら**: 非同期ビデオメモ（テック要素が明確・1週間以内）
- **BtoB収益化を最速で狙うなら**: 職人向け見積もりSaaS（課題が明確・単価高い）
- **長期的に大きくするなら**: AIパーソナル財務コーチ（データ蓄積が価値になる）
- 海外実績がある＝「需要の検証」は完了済みという強み。日本語・日本文化・日本の法制度への対応が最大の差別化かつ参入障壁になる。
