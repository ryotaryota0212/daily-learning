# 既存サービスの不満から生まれるビジネスチャンス

**作成日**: 2026-09-17  
**テーマ**: 既存サービスへの不満・ペインポイントを起点にした新サービス創出

---

## 市場概要

「不満」は最強のプロダクト・マーケット・フィット指標である。既存サービスが解決できていない課題を正確に捉えることで、既存ユーザーを置き換えるチャンスが生まれる。

### 現在の主な不満トレンド
- **Notionへの不満**: 重い・複雑すぎる・AI機能が中途半端
- **Slackへの不満**: 通知過多・無料プランのメッセージ保存制限・高額
- **Zoomへの不満**: 会議後のフォローアップが手動・録画管理が面倒
- **Figmaへの不満**: 月額高騰（2023年以降）・デザイン以外のコラボが弱い
- **Airtableへの不満**: 高すぎる・開発者向けすぎる・日本語サポート不足
- **GitHubへの不満**: Issue管理が貧弱・AI補完がCopilot課金必須

---

## 具体的なサービスアイデア

### アイデア1: `MeetingMemo` — 会議後フォローアップ自動化ツール

**Zoomの不満**: 「会議後のアクションアイテム整理が手動で面倒」「録画を誰も見返さない」

**サービス概要**
- Zoom/Meet/Teams の録画・文字起こしを自動取得
- AIがアクションアイテムを抽出し、担当者ごとにタスク化
- Slack/Notionへ自動投稿、期日管理まで一貫サポート

**想定ユーザー**
- 週10時間以上会議があるスタートアップ・中小企業のチーム
- プロジェクトマネージャー、人事・採用担当

**収益モデル**
- フリーミアム（月10会議まで無料）
- Pro: ¥1,980/ユーザー/月（無制限 + CRM連携）
- Team: ¥4,980/5ユーザー/月

**技術スタック（個人開発向け）**
- Nuxt3 + FastAPI + Neon (PostgreSQL)
- Whisper API（文字起こし）、Claude API（要約・タスク抽出）
- Zoom/Google Meet Webhook連携

**差別化ポイント**
- 日本語に最適化した文字起こし精度
- タスク管理まで一気通貫（録画ビューワーに終わらない）

**個人開発で作れるか**: ◎ MVPは2〜3週間で構築可能。外部API依存が多く、コアロジックはAI任せにできる。

### アイデア2: `SlimNote` — Notionの「軽量・シンプル版」

**Notionへの不満**: 「機能が多すぎて重い」「個人メモに使うには大げさ」「AIが別課金」

**サービス概要**
- マークダウンベースのシンプルノート + AIアシスト内蔵（追加課金なし）
- 検索・タグ・リンク機能に絞った高速UI
- オフライン対応、ローカル優先でプライバシー重視

**想定ユーザー**
- Notionから離脱したソロワーカー・フリーランス
- メモアプリにAI補完を求めているが高額課金は避けたい層
- エンジニア・ライター

**収益モデル**
- 無料（ローカル保存 + 基本AI10回/日）
- Pro: ¥980/月（AI無制限 + クラウド同期 + チーム共有）

**技術スタック**
- Nuxt3 (PWA対応) + SQLite/Neon + FastAPI
- Claude API（ライティング補助・要約）
- IndexedDB（オフラインキャッシュ）

**差別化ポイント**
- AIが標準搭載で追加課金なし
- 「速さ」に徹底集中（Notion比3倍高速を謳う）
- データポータビリティ（Markdownで全エクスポート）

**個人開発で作れるか**: ◎ UIはシンプルなため1週間でMVP可能。競合が多いが日本語特化で差別化余地あり。

---

### アイデア3: `Gridlite` — Airtableの「価格破壊版」日本語SaaS

**Airtableへの不満**: 「月額$20/ユーザーは中小には高すぎる」「日本語UIが貧弱」「複雑すぎる」

**サービス概要**
- スプレッドシート × データベース の中間UIを日本語ネイティブで提供
- 在庫管理・顧客管理・案件管理などのテンプレートを30種類提供
- APIエンドポイント自動生成（簡易バックエンドとして使える）

**想定ユーザー**
- 中小企業・個人事業主（Excelから脱却したいが開発リソースがない）
- EC事業者、不動産・建設業など非IT業種

**収益モデル**
- フリー: 3テーブル・1,000行まで
- ビジネス: ¥1,480/ユーザー/月（無制限テーブル・API）
- エンタープライズ: 要相談

**技術スタック**
- Nuxt3 + FastAPI + Neon
- Handsontable or AG Grid（テーブルUI）
- Row Level Security（Neon/Supabase）

**差別化ポイント**
- Airtable比で約1/4の価格
- 日本のビジネス慣習に合ったテンプレート（見積書・請求書連携）
- 独自ドメインでの公開フォーム生成機能

**個人開発で作れるか**: △ テーブルUIの複雑さとデータ整合性の担保が難しい。3〜4週間でMVP、フル機能は3ヶ月目安。

---

### アイデア4: `GitFlow AI` — GitHubのIssue管理をAIで強化するChrome拡張

**GitHubへの不満**: 「Issueの整理・優先順位付けが手動で面倒」「PRのレビュー依頼が埋もれる」

**サービス概要**
- GitHub上で動くChrome拡張 + バックエンドAPI
- Issueを自動分類・優先度付け・重複検知
- PRのレビュー待ち時間・コードの影響範囲をビジュアル化

**想定ユーザー**
- GitHubを使うスタートアップのエンジニアチーム（5〜30人規模）
- OSS メンテナー

**収益モデル**
- 個人: 無料（リポジトリ1件まで）
- Team: $9/月（5リポジトリ、3人まで）
- Pro: $29/月（無制限）

**技術スタック**
- Chrome Extension (Manifest V3) + Nuxt3 管理画面
- FastAPI + Neon + GitHub API
- Claude API（Issue分類・重複検知）

**差別化ポイント**
- GitHub UI上に直接オーバーレイ表示（ツール切り替え不要）
- Linear/Jiraのような重厚なPMツールと違い、GitHub-native

**個人開発で作れるか**: ◎ Chrome拡張 + 軽量APIのため1〜2週間でMVP。GitHub API制限に注意が必要。

## 実現可能性の評価

| アイデア | 開発難易度 | 市場規模 | 競合強度 | 個人開発適性 |
|---------|-----------|---------|---------|------------|
| MeetingMemo | ★★☆ | 大（全業種） | 中 | ◎ |
| SlimNote | ★☆☆ | 中（個人〜SMB） | 高 | ◎ |
| Gridlite | ★★★ | 大（中小企業） | 低（日本） | △ |
| GitFlow AI | ★★☆ | 中（開発チーム） | 低 | ◎ |

### 総評
- **最速でマネタイズするなら**: SlimNote（競合多いが既存不満層が明確）
- **穴場狙いなら**: GitFlow AI（GitHub依存で既存ユーザー獲得が容易）
- **長期的に大きく育てるなら**: Gridlite（日本のSMB市場は競合が手薄）
- **BtoBで安定収益を得るなら**: MeetingMemo（Zoom/Teams連携で企業導入しやすい）

### 「個人開発者が1人で作れるか」の観点
- MeetingMemo・SlimNote・GitFlow AIは**1人で十分実現可能**
- Nuxt3 + FastAPI + Neon の技術スタックで統一すれば、コンテキストスイッチを最小化できる
- AIサービス（Claude API、Whisper API）を積極活用することで、開発工数を半減できる
- 初月は無料プランで100ユーザー獲得を目標とし、PMFを確認してから有料化するアプローチが有効
