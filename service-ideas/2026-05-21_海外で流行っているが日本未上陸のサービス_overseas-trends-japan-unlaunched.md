# 海外で流行っているが日本未上陸のサービス

**作成日**: 2026-05-21  
**テーマ領域**: #10 海外で流行っているが日本未上陸のサービス

---

## 市場概要

- 米国・欧州で検証済みのPMFを持つサービスを日本ローカライズするのは、リスクを抑えた起業戦略として有効
- 日本市場は「デジタル化の遅れ」「独自商習慣」「英語コンテンツへの抵抗」という3つの壁が参入障壁を生み出している
- 一方でスマートフォン普及率・可処分所得・サブスク受容度はいずれも高く、タイミングが合えば急速に普及する

### 注目すべき日本未上陸ジャンル（2026年時点）

| ジャンル | 海外代表例 | 日本での空白理由 |
|---|---|---|
| AI法律相談 (Consumer) | DoNotPay, Harvey | 弁護士法72条の規制懸念 |
| 職人・技術者マッチング | Thumbtack, Angi | リクルート系が独占するも体験が古い |
| コミュニティ主導型ECファンド | Rally Rd, Otis | 金融規制・少額投資文化の未成熟 |
| メンタルヘルスコーチング | BetterHelp, Talkspace | 精神科受診への stigma、オンライン診療解禁の遅れ |
| ノーコードAI業務自動化 | Make (Integromat), n8n | ITリテラシーギャップ、日本語対応不足 |

## 具体的なサービスアイデア

### アイデア1: 「テ職人」— 職人・技術者オンデマンドマッチング

**概要**: Thumbtackの日本版。水道工事・電気工事・引越し・リフォームなどの職人を即日〜翌日でマッチング。

**想定ユーザー**
- 発注側: 30〜50代の住宅オーナー、賃貸管理会社、不動産オーナー
- 受注側: 独立職人・小規模工務店（現在は口コミだけで集客）

**収益モデル**
- 職人側からの月額掲載料（¥3,000〜¥15,000/月）
- 成約手数料（案件金額の8〜12%）
- 保険・資格証明バッジの有料オプション

**技術スタック（個人開発想定）**
- フロント: Nuxt 3（SSR＋PWA対応）
- API: FastAPI + PostgreSQL (Neon)
- マッチングロジック: エリア・資格・評価スコアでのベクトル検索
- 決済: Stripe Connect（職人への分配自動化）

**差別化ポイント**
- 職人の資格・免許を写真OCRで自動検証（AI活用）
- 案件完了後の自動リマインダーで口コミ収集率を上げる
- 「施主−職人」間のチャット履歴を工事記録として保管（次回発注時に再利用）

**個人開発可能性**: ★★★☆☆  
マッチング系はMVPは作れるが、供給側（職人）獲得のオフライン営業が必要。最初の1都市に絞って地道に。

---

### アイデア2: 「こころコーチ」— セルフケア特化メンタルヘルスコーチングアプリ

**概要**: BetterHelpの「診療ではなく予防・セルフケア」に絞った日本版。臨床心理士・公認心理師によるテキストコーチング。

**想定ユーザー**
- 精神科受診には抵抗があるが「なんとなく辛い」20〜40代会社員
- 産後うつ・育児疲れを抱える育休中の親

**収益モデル**
- 月額 ¥4,980（コーチとの週1回テキスト交換＋AIチェックイン無制限）
- 法人向け EAP（従業員支援プログラム）プラン: ¥500/人/月〜

**技術スタック**
- フロント: Nuxt 3 + Capacitor（iOS/Androidラップ）
- バックエンド: FastAPI
- DB: Neon (PostgreSQL)
- AIチェックイン: Claude API（Haiku）を使った感情ログ分析＆提案
- ビデオ/テキスト: Twilio or Socket.IO

**差別化ポイント**
- 「診療行為でない」点を明示し弁護士確認済みのコンプライアンス設計
- AIが毎日の気分ログをトレンド分析し、コーチに週次サマリーを自動生成
- 「受診が必要」と判断したら提携クリニックへのシームレスな紹介

**個人開発可能性**: ★★★★☆  
技術的には作りやすい。コーチ確保（業務委託契約）が初期ハードル。法的グレーゾーン確認は必須だが、セルフケア領域なら参入可能。

---

### アイデア3: 「Automa JP」— 日本語特化ノーコードAI業務自動化

**概要**: Make (旧Integromat) ・Zapierの日本語UIとローカルサービス連携に特化した版。

**想定ユーザー**
- kintone・freee・MoneyForward・楽楽精算など日本製SaaSを使うSMB（従業員10〜100名）
- 社内業務改善担当の非エンジニア

**収益モデル**
- フリープラン（タスク1,000回/月）＋ Pro ¥2,980/月（10,000タスク）＋Business ¥9,800/月（100,000タスク）
- 日本製SaaSベンダーとのリセラー契約（ kintoneプラグイン経由で送客）

**技術スタック**
- フロント: Nuxt 3（ビジュアルフロービルダーはVue Flow）
- バックエンド: FastAPI（ワーカーキュー: Celery + Redis）
- DB: Neon (PostgreSQL)
- 連携: 各SaaSの公式API + Webhook受信エンドポイント
- AI自然言語→フロー変換: Claude API (Sonnet)

**差別化ポイント**
- 「kintone↔freee↔Slack↔LINE WORKS」など国産SaaSコネクタを優先整備
- 自然言語でフローを記述するとAIが自動生成（「受注したらSlackに通知してfreeeに売上登録」）
- 国内データセンター（さくらVPS等）でのデータ処理オプション（ISMS・Pマーク対応企業向け）

**個人開発可能性**: ★★★★★  
MVPはNuxt + FastAPI + Celeryで2〜3週間で構築可能。コネクタを1つずつ増やす戦略でリリース後も継続改善できる。個人開発に最も向いているアイデア。

---

### アイデア4: 「パスタイム」— コレクティブル少額投資プラットフォーム

**概要**: Rally Rdの日本版。ヴィンテージカー・スニーカー・アート・マンガ原画などを小口化し、1口1,000円から投資可能に。

**想定ユーザー**
- 20〜35歳の投資初心者、サブカルチャー愛好家
- アイテムを手放したいコレクター（出口戦略として）

**収益モデル**
- オファリング手数料（資産価値の5%）
- 二次流通での取引手数料（2.5%）
- 保管・保険費用のマークアップ

**技術スタック**
- フロント: Nuxt 3
- バックエンド: FastAPI
- DB: Neon
- 決済/KYC: Stripe + eKYC API
- ブロックチェーン（任意）: Polygon上でのNFT証書（ガス代を最小化）

**差別化ポイント**
- 金融商品取引法の「電子募集取扱業者」登録が必要なため参入障壁が高い（競合が少ない）
- AIによる資産評価（過去オークション相場データ学習）

**個人開発可能性**: ★☆☆☆☆  
金融ライセンス取得が必須のため個人では現実的に難しい。共同創業者（弁護士・ファイナンス経験者）が必要。

### 推奨アクション

**最短でマネタイズしたい個人開発者→ Automa JP**
- 日本製SaaSのkintone連携から着手し、10社のβユーザーを無料で獲得
- PMF確認後に有料プラン導入

**スタートアップとして資金調達を狙うなら→ こころコーチ**
- メンタルヘルス市場は投資家の注目度が高い
- EAPプランでB2B展開することで解約率を低く保てる
