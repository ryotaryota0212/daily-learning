## 市場概要

- サブスクリプション市場は2025年時点で世界全体で約1.5兆ドル規模（Zuora調べ）
- SaaS・コンテンツ・物理サブスク問わず「解約率の管理」と「LTV最大化」が生死を分ける
- 成功企業の共通点: ①価値の習慣化、②ネットワーク効果、③データ蓄積による個別最適化
- 個人開発サブスクの月収$3,000〜$10,000達成事例が急増（Indie Hackersで多数確認）

## 具体的なサービスアイデア

### 1. 小規模EC向け「返品・カスタマー対応AI代行」サブスク

**想定ユーザー**: Shopify / BASE / minne で月商100万円以下の個人EC事業者  
**痛み**: 返品対応・クレームメールに週5〜10時間を浪費している  
**サービス概要**: 店舗のFAQと過去メール履歴を学習させたAIが、問い合わせの80%を自動返信。残りは要約してオーナーに転送。

- **収益モデル**: 月額2,980円〜（メール件数別ティア）
- **技術スタック**: Next.js + FastAPI + Neon + Claude API（メール解析）+ SendGrid
- **差別化**: 日本語ECに特化・Shopify / BASE プラグイン対応・設定5分
- **個人開発可否**: ◎ 1人で2〜3週間で MVP 可能。API費用は従量課金で初期投資ほぼゼロ

---

### 2. フリーランサー向け「提案書・契約書テンプレ月額配信」

**想定ユーザー**: デザイナー・エンジニア・コンサルのフリーランサー（国内約300万人）  
**痛み**: 提案書や契約書を毎回ゼロから作るのは時間の無駄・法的リスクも不安  
**サービス概要**: 業種別テンプレートを毎月10〜20本配信＋AI入力補完で5分で完成。法改正対応も自動更新。

- **収益モデル**: 月額980円（個人）/ 2,980円（チーム最大5人）
- **技術スタック**: Nuxt 3 + Supabase + PDF生成（puppeteer）+ Stripe
- **差別化**: 弁護士監修テンプレ・日本の下請法・フリーランス保護法に準拠・ダウンロード数制限なし
- **個人開発可否**: ○ テンプレ制作に外注費がかかるが、ツール部分は1人1週間。初月から黒字化しやすい

---

### 3. 「読了管理 × 次の本AI推薦」サブスク（読書家向け）

**想定ユーザー**: 月2〜5冊読む30〜50代ビジネスパーソン  
**痛み**: 読んだ本を忘れる・次に何を読めばいいかわからない・Amazonレコメンドは広告ばかり  
**サービス概要**: 読了本を記録すると、AI が「あなたの思考のクセ」を分析し、盲点を埋める本を週1冊推薦。感想メモを蓄積してナレッジグラフ化。

- **収益モデル**: 月額480円（記録のみ無料）/ 月額980円（AI推薦フル機能）
- **技術スタック**: React Native + FastAPI + Neon + Claude API（書評解析）+ 楽天Books API
- **差別化**: Audible・読書メーターは記録止まり。「次の行動変容」まで繋げる点が独自
- **個人開発可否**: ◎ モバイルアプリだが React Native で iOS/Android 同時対応。データが溜まるほど価値が上がる典型的な習慣化型サブスク

## 実現可能性の評価

| 項目 | アイデア1(EC返品AI) | アイデア2(提案書テンプレ) | アイデア3(読書推薦) |
|---|---|---|---|
| 開発難易度 | 中 | 低〜中 | 中 |
| 競合の少なさ | 高（日本語特化が希少） | 中 | 中 |
| 解約率の低さ予測 | 高（業務依存度大） | 中 | 中 |
| 個人開発で成立 | ◎ | ◎ | ◎ |
| 月収$3,000達成目安 | 約300ユーザー | 約3,000ユーザー | 約3,000ユーザー |

### 総評

- **最も早く収益化できる**: アイデア2（テンプレ配信）— ツール開発より素材調達が鍵
- **LTVが最も高い**: アイデア1（EC代行）— 解約するとオーナーが困るため継続率◎
- **スケールしやすい**: アイデア3（読書）— データが競合壁になる・海外展開も狙える
- **共通の成功要因**: 「使い続けるほど価値が上がる設計」＋「解約の心理コストを高める仕組み」が必須
