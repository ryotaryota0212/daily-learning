# 既存サービスの不満から生まれるビジネスチャンス

**作成日**: 2026-09-06  
**テーマ領域**: 既存サービスの不満から生まれるビジネスチャンス

---

## 市場概要

「Scratching your own itch（自分の痒いところを掻く）」は個人開発成功の黄金律。  
既存サービスへの不満は最も信頼できる市場シグナルであり、Reddit・Twitter・App Storeレビューに埋まっている。

### 不満が集まりやすい構造的な理由
- 大手は全ユーザー対応を優先→ニッチなニーズが切り捨てられる
- レガシー技術でUXが古くなったまま放置されるプロダクト
- 料金プランが実態と合わない（中間層を無視した高/低の二極化）
- 企業向け機能に傾いて個人・小規模の使い勝手が悪化

## 具体的なサービスアイデア

### 1. Notionの「データベース複雑すぎ問題」を解決するシンプル情報管理ツール

**不満の出所**  
- 「Notionはできすぎて逆に使いこなせない」がReddit/Twitterで定期バズ
- データベース・リレーション・フォーミュラの学習コストが高い
- 個人メモ用途には過剰、Obsidianはエンジニア向け

**想定ユーザー**
- 非エンジニアのフリーランサー・クリエイター（デザイナー、ライター）
- 「なんでも管理したいが、設定に時間を使いたくない」30代

**収益モデル**
- フリーミアム：無料は50ページまで、月額$6でunlimited
- 年間払い割引（20%オフ）でLTV向上

**技術スタック**
- Nuxt 3（フロント）+ FastAPI（API）+ Neon（DB）+ TipTap（エディタ）
- Vercel / Railway でホスティング

**差別化ポイント**
- 「ページ」と「タグ」の2概念だけでほぼすべてを整理できるUX設計
- テンプレートを選ぶだけで即使える（設定ゼロスタート）
- Notionからのインポート機能で乗り換えコスト最小化

**個人開発可能性**: ◎ エディタはTipTap流用、DBスキーマはシンプル。2〜3週間でMVP可能。

### 2. Calendlyの「一方的すぎる」問題を解くダブルコンセント予約ツール

**不満の出所**
- Calendlyリンクを送るのが「失礼」と感じる文化的摩擦（日本・欧州）
- 予約後のリマインダーが煩わしい・カスタマイズできない
- 無料プランで複数イベントタイプが持てない

**想定ユーザー**
- フリーランサー・コンサルタント（月5〜30件の面談調整）
- 採用担当者・営業パーソン（相手への配慮を大切にする職種）

**収益モデル**
- 月額¥980（個人）/ ¥2,980（チーム3人まで）
- 年払いで2ヶ月分無料

**技術スタック**
- Nuxt 3 + FastAPI + Neon + Google Calendar API / Outlook API
- メール送信：Resend

**差別化ポイント**
- 「候補日を複数提示→相手が選択→双方確認」の3ステップフロー
- 日本語ファーストのUI、敬語テンプレート内蔵
- Zoomリンク自動発行、Slack通知連携

**個人開発可能性**: ○ Calendar APIの認証が最大の難所。ただしOAuth2の実装経験があれば4週間以内にMVP。

### 3. Zapierの「高すぎる・複雑すぎる」を狙う国産ノーコード自動化ツール

**不満の出所**
- Zapierの無料プランは月100タスクで実用に足りない
- 有料は月$20〜→個人・小規模には重い
- Make（旧Integromat）はUIが難解すぎる
- 日本語サポートがほぼない

**想定ユーザー**
- 中小企業の業務改善担当（IT専門外）
- 士業・クリエイターなど個人事業主
- 国産SaaS（Freee、Chatwork、LINE等）との連携ニーズが高い層

**収益モデル**
- 月額¥1,480（個人・月1,000タスク）/ ¥4,800（チーム・月10,000タスク）
- 初期はSMBに絞り、成功事例でエンタープライズへ拡大

**技術スタック**
- Nuxt 3（フロー設計UI）+ FastAPI（実行エンジン）+ Neon + Redis（キュー）
- Webhookハンドラ + 各SaaS SDK

**差別化ポイント**
- 国産SaaSのコネクタを最優先（Freee・Chatwork・Sansan・KING OF TIME）
- テンプレートマーケットプレイス（ユーザー投稿→収益シェア）
- 「何が動いているか」が視覚的にわかる実行ログ

**個人開発可能性**: △ 実行エンジンは複雑。ただしコネクタを絞れば（最初は5つ）MVP判定は可能。3〜4ヶ月のプロジェクト。

### 4. Loomの「重すぎる・録画管理が雑」問題を解く軽量動画メモツール

**不満の出所**
- Loomは録画後の整理UIが弱い（フォルダ管理が難しい）
- 無料プランの25動画上限に当たる
- AIの要約・トランスクリプトは有料プランのみ
- 「チームで使う前提」の設計で個人使いに不向き

**想定ユーザー**
- リモートワーカー（非同期コミュニケーション目的）
- 個人チュートリアル作成者（教育系コンテンツメーカー）

**収益モデル**
- 無料：月5録画・最大5分 / 月額¥480：無制限
- AI文字起こし（Whisper）はオプション課金¥200/月

**技術スタック**
- Nuxt 3 + FastAPI + Neon + MediaRecorder API（ブラウザ録画）
- 動画ストレージ：Cloudflare R2（コスト最安）
- AI文字起こし：OpenAI Whisper API

**差別化ポイント**
- タグ＋全文検索で動画内の発言から目的シーンを即検索
- 1クリックでチャプター自動生成（Whisperベース）
- 軽量：インストール不要、ブラウザ拡張だけで動作

**個人開発可能性**: ◎ MediaRecorder APIとR2の組み合わせは実績多数。1ヶ月でMVP十分可能。

## 実現可能性の評価

| アイデア | 難易度 | 市場規模 | 個人開発 | 収益化速度 |
|---|---|---|---|---|
| シンプル情報管理 | 中 | 大 | ◎ | 速い |
| ダブルコンセント予約 | 中 | 中 | ○ | 中 |
| 国産ノーコード自動化 | 高 | 大 | △ | 遅い |
| 軽量動画メモ | 中 | 中 | ◎ | 速い |

### 最優先推奨：シンプル情報管理ツール

- Notion/Obsidian/Roamへの不満は継続的・構造的（競合が複雑化し続ける）
- 「シンプルであること」自体がバリュープロポジション→大手が真似しにくい
- SaaS最小構成（テキストDB + 認証 + サブスク決済）で最速MVP
- 月$6×1,000人＝$6,000MRR到達が現実的な12ヶ月目標

### 個人開発者向けの全体アドバイス
- Reddit・App Storeの1〜2星レビューを100件読む→共通する不満を3つ抽出
- 「既存サービスのXX機能だけ」を切り出すのが最も低リスクな参入戦略
- 競合の無料プラン制限を逆手に取った価格設定が有効
