# 海外で流行っているが日本未上陸のサービス

作成日: 2026-06-26

## 市場概要

- 欧米・東南アジアで急成長しているサービスでも、日本に上陸していないケースは多い
- 主な理由: 日本語ローカライズのコスト、決済インフラの差異、商習慣の違い
- 逆に言えば、「海外で実証済み × 日本未参入」は個人開発者にとって最大のヒント
- 2024〜2026年のトレンドを踏まえ、日本で勝ち目があるカテゴリを分析する

---

## 具体的なサービスアイデア

### 1. AI家計・財務コーチ（Copilot Money の日本版）

**元ネタ**: Copilot Money（米国）/ Emma（英国）
- 欧米では「AIが支出を分析して次のアクションを提案する」財務コーチアプリが急成長
- 日本では家計簿アプリ（マネーフォワード・Zaim）はあるが、「提案型コーチング」は弱い

**想定ユーザー**
- 20〜35歳の共働き夫婦・単身フリーランス
- 節約したいが何から手をつけるか分からない層

**収益モデル**
- 月額980円のサブスク（フリープランあり）
- 提携金融機関からの送客アフィリエイト（NISAや保険）

**技術スタック**
- Nuxt 3 + FastAPI + Neon (PostgreSQL)
- 銀行連携: Money Forward Open API または Moneytree Link
- AI提案: Claude API（claude-sonnet-4-6）でのパーソナライズされた財務アドバイス生成

**差別化ポイント**
- 単なる集計でなく「今月サブスク3本解約すると年3.6万円浮く」という具体的な提案
- 日本の税制（ふるさと納税・iDeCo）に特化したアドバイス

**個人開発可能性**: ◎（銀行API契約が最大ハードル。Moneytree Linkは個人でも審査可）

---

### 2. 非同期ビデオレビューツール（Loom の業務特化版）

**元ネタ**: Loom（米国）/ Claap（フランス）
- 欧米では「Zoomを使わず動画で非同期レビュー」が当たり前になっている
- 日本のSMBはまだオンライン会議中心で、非同期文化への移行が遅れている

**想定ユーザー**
- 在宅勤務チームのマネージャー・デザイナー・開発チーム
- 「議事録を書く時間がない」「テキストで説明しきれない」人

**収益モデル**
- チームプラン: 月額3,500円/ユーザー（5人〜）
- 無料プランは動画5本・5分以内に制限
- 年払い割引（20%オフ）でARR安定化

**技術スタック**
- Nuxt 3 + FastAPI
- 動画ストレージ: Cloudflare R2（低コスト）
- 文字起こし: Whisper API
- リアルタイム録画: MediaRecorder API（ブラウザのみでOK）

**差別化ポイント**
- 録画URLをSlack/Notionに貼るだけで埋め込み再生
- 日本語字幕の自動生成・タイムスタンプコメント
- 「見ました」ボタン一つで既読管理（メール通知不要）

**個人開発可能性**: ◎（Cloudflare R2 + Whisper で低コスト実装可能。1週間でMVP）

---

### 3. ローカルビジネス向けAIレビュー返信SaaS（Birdeye の軽量版）

**元ネタ**: Birdeye / Widewail（米国）
- 米国では飲食店・クリニック・不動産業者がGoogleレビューに自動返信するSaaSが急成長
- 日本のGoogleビジネスプロフィール利用は急増しているが、返信ツールはほぼゼロ

**想定ユーザー**
- 飲食店オーナー・美容院・歯科医院・整骨院（1〜5店舗規模）
- Googleレビューが増えても返信が追いつかないオーナー

**収益モデル**
- 月額3,980円/店舗（返信AIは無制限）
- 初月無料トライアル → 解約率が低いカテゴリ（インフラ系ツール）
- 代理店チャネル（MEO対策会社に卸す）

**技術スタック**
- Nuxt 3 + FastAPI + Neon
- Google Business Profile API で口コミ取得・返信投稿
- 返信生成: Claude API（claude-haiku-4-5 でコスト最適化）
- キュー管理: FastAPI BackgroundTasks または Celery

**差別化ポイント**
- 「店舗のトーン・口調」を学習して自然な返信を生成
- 低評価レビューには「まず謝罪・解決提案・連絡先」のテンプレ構成
- LINEで返信確認→承認フローに対応（日本のオーナー向け）

**個人開発可能性**: ◎（最短3日でMVP。Google API登録が唯一のハードル）

---

### 4. フリーランス向け自動請求・入金催促SaaS（Bonsai の日本版）

**元ネタ**: Bonsai / HoneyBook（米国）
- 欧米ではフリーランスの契約〜請求〜入金催促を自動化するオールインワンSaaSが普及
- 日本では「請求書=freee/MF」で終わっており、催促・契約管理は未整備

**想定ユーザー**
- フリーランスエンジニア・デザイナー・ライター（副業含む）
- 「請求書を送った後の催促が気まずくて言えない」人

**収益モデル**
- 月額1,480円のサブスク（個人フリーランス向け）
- 成功報酬型オプション: 入金確認済み請求額の0.5%（任意）

**技術スタック**
- Nuxt 3 + FastAPI + Neon
- メール自動送信: Resend
- 電子署名: DocuSign API or Acrobat Sign（もしくは独自実装）
- 請求書PDF生成: WeasyPrint（Python）

**差別化ポイント**
- 「X日後に自動で催促メールを送る」設定だけで入金率が上がる
- 「角の立たない文面」をAIが自動生成（日本語の敬語バリエーション対応）
- Notionのデータベースと連携し案件ステータスを同期

**個人開発可能性**: ◎（Resend + WeasyPrint で1週間でMVP可能）

## 総括・個人開発者へのアドバイス

- **最初に試すなら「AIレビュー返信SaaS」**: 技術的難度が低く、ユーザーの痛みが明確で、B2Bなので解約率が低い
- **海外実績のあるカテゴリ**は「需要があることの証明」が済んでいるため、PMF探索コストが低い
- 日本語ローカライズ・LINE連携・日本語での敬語対応が「海外サービスに対する唯一の参入障壁」になる
- PoC（概念実証）は1週間以内に出し、10人のβユーザーに無料で使ってもらうことが成功への最短ルート
