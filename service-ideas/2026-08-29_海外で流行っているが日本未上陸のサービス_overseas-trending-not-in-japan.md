# 海外で流行っているが日本未上陸のサービス

作成日: 2026-08-29

## 市場概要

- 海外（主に米国・欧州）で成立しているサービスカテゴリが日本市場に未参入のケースは多い
- 理由: 言語対応コスト・規制差異・商習慣の違い・ローカライズリスク
- 逆に言えば「日本語対応 + 日本商習慣対応」を先に作った個人開発者が市場を取れるチャンスが存在する
- 2026年現在、円安傾向の継続により海外ツールのコスト増が国内代替需要を押し上げている

---

## 具体的なサービスアイデア

### 1. Loom代替の非同期ビデオレビューツール（日本語UI特化）

**海外元ネタ**: Loom（米国で非常に普及、Atlassianが買収）

**想定ユーザー**
- 日本のリモートワーク中小企業
- フリーランスのデザイナー・エンジニア（クライアントへのレビュー動画送付）
- 社内研修担当者

**収益モデル**
- 無料プラン（月5本まで）→ 有料プラン ¥1,480/月（無制限）
- チームプラン ¥3,800/月/5名

**技術スタック**
- フロントエンド: Nuxt 3
- バックエンド: FastAPI
- DB: Neon（PostgreSQL）
- 動画ストレージ: Cloudflare R2
- 録画: MediaRecorder API（ブラウザネイティブ）

**差別化ポイント**
- UI全面日本語、会社員向けの「承認依頼」ワークフロー統合
- Slackではなく日本企業に多いChatwork・LINE WORKS連携
- 月額コストをLoom（$15/月〜）の半額以下に設定

**個人開発者1人で作れるか**: ○ 可能。録画機能はブラウザAPIで実装できる。動画変換はFFmpeg on Lambdaで解決。MVP は3〜4週間で構築可能。

---

### 2. 弁護士・士業向け依頼管理SaaS（Clio日本版）

**海外元ネタ**: Clio（カナダ発、法律事務所向けSaaSで年間ARR $200M超）

**想定ユーザー**
- 弁護士・司法書士・行政書士の小規模事務所（1〜5名）
- 税理士事務所（顧問契約管理）

**収益モデル**
- ¥9,800/月/事務所（案件管理・請求書・タイムトラッキング一体型）
- 電子契約連携オプション ¥2,000/月追加

**技術スタック**
- フロントエンド: Nuxt 3 + Tailwind
- バックエンド: FastAPI
- DB: Neon
- PDF生成: WeasyPrint
- 電子契約: クラウドサイン API 連携

**差別化ポイント**
- 日本の弁護士費用基準・源泉徴収対応の請求書自動生成
- 依頼者へのポータル（進捗確認・書類提出）を標準装備
- 弁護士ドットコムや法テラス案件のインポート対応

**個人開発者1人で作れるか**: △ 難しいが不可能ではない。ドメイン知識（法律事務所業務フロー）の調査に時間がかかる。既存士業との共同開発が推奨。MVPは2〜3ヶ月。

---

### 3. 一人オーナー向け予約・顧客管理オールインワン（Vagaro日本版）

**海外元ネタ**: Vagaro（米国の美容師・ネイリスト・パーソナルトレーナー向け予約管理SaaS、年間$1B評価）

**想定ユーザー**
- 一人経営の美容師・ネイリスト・エステティシャン
- フリーランスのパーソナルトレーナー・ヨガインストラクター

**収益モデル**
- 月¥2,980（予約管理 + 顧客カルテ + LINE通知 + 売上レポート）
- 決済手数料: 売上の2.5%（Stripe経由）

**技術スタック**
- フロントエンド: Nuxt 3（予約ページはSSRで高速表示）
- バックエンド: FastAPI
- DB: Neon
- 通知: LINE Messaging API
- 決済: Stripe Connect

**差別化ポイント**
- LINEで予約確認・リマインドが完結（日本の顧客文化に最適化）
- 顧客カルテ（施術メモ・アレルギー情報）をスマホから手軽に更新
- Googleカレンダー同期 + 自動ダブルブッキング防止

**個人開発者1人で作れるか**: ◎ 非常に作りやすい。予約カレンダー + カルテ + LINE通知の組み合わせでMVP 2〜3週間。ターゲットが明確でペインも深い。

---

### 4. フリーランス契約書・SOW自動生成ツール（Bonsai日本版）

**海外元ネタ**: Bonsai（フリーランス向け契約書・請求書・税務一体型ツール、米国で人気）

**想定ユーザー**
- デザイナー・エンジニア・ライターなど業務委託フリーランス
- 副業ワーカー（法人との契約書を自分で作る必要がある人）

**収益モデル**
- 無料（月3件まで）→ ¥1,280/月（無制限 + 電子署名）
- 法人向けチームプラン ¥4,800/月

**技術スタック**
- フロントエンド: Nuxt 3
- バックエンド: FastAPI
- DB: Neon
- PDF生成: WeasyPrint または Puppeteer
- 電子署名: DocuSign API または独自実装

**差別化ポイント**
- 日本の業務委託契約・下請法対応テンプレートを標準収録
- インボイス制度対応の請求書を自動生成
- 「週払い・月払い・マイルストーン払い」の支払いスケジュール管理

**個人開発者1人で作れるか**: ○ 可能。テンプレートエンジン + PDF生成 + 電子署名の組み合わせ。法的に問題ないテンプレート作成に弁護士への確認コスト（数万円）が必要だが、それを超えると非常にスケールしやすい。

## 実現可能性の評価

| サービス | 個人開発難易度 | 市場規模 | 競合状況 | 推奨度 |
|---|---|---|---|---|
| 非同期ビデオレビュー | ★★☆（中） | 中 | 低（Loomは英語のみ） | ★★★★☆ |
| 士業向け依頼管理 | ★★★（高） | 中〜大 | 低 | ★★★☆☆ |
| 一人オーナー予約管理 | ★☆☆（低） | 大 | 中（ホットペッパーが強い） | ★★★★★ |
| フリーランス契約書生成 | ★★☆（中） | 中 | 低〜中 | ★★★★☆ |

## まとめ・優先度

- **最短で収益化できる**: 一人オーナー向け予約管理（痛みが明確、LINEで差別化）
- **長期的に大きくなる**: 士業向け依頼管理（参入障壁が高い分、定着率も高い）
- **副業・週末プロジェクトとして始めやすい**: フリーランス契約書生成・非同期ビデオレビュー
- 共通戦略: まず**特定のコミュニティ（Xのフリーランスコミュニティ等）でβ版無料提供 → 口コミで広げる**が有効
