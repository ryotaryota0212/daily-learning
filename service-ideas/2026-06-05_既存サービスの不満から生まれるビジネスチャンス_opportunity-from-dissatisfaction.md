## 市場概要

「不満」はプロダクト市場に最も確実に存在するシグナルのひとつ。大手SaaSが肥大化・複雑化する中、「機能は多いが使いにくい」「高すぎる」「UIが古い」などの不満がReddit・X・AppStoreレビューに溢れている。個人開発者にとって、こうした不満を起点にしたニッチ特化プロダクトは参入コストが低く成功確率が高い。

### 典型的な不満パターン
- **価格の高騰**: Notion・Slack・Figmaなどが値上げを繰り返し、中小・個人ユーザーが離れる
- **機能過多**: 必要な機能の10%しか使わないのに全額払わされる
- **UIの複雑化**: 機能追加のたびに操作が煩雑になる
- **データ所有権**: クラウドに閉じ込められてエクスポートが困難
- **API制限・価格体系の不透明さ**: 突然のプラン変更や利用制限

## 具体的なサービスアイデア

### アイデア1: **SlimNote** — Notion離れユーザー向けシンプルWiki

**背景**: Notionは2024〜2025年にかけて大幅値上げ＋AI機能の強制バンドルで離脱者が続出。「データベースは不要、Markdownメモとページリンクだけでいい」という需要が根強い。

- **想定ユーザー**: フリーランサー・個人ブロガー・小規模チーム（2〜10人）
- **収益モデル**: フリーミアム（個人無料 / チーム $5/月）+ セルフホスト版の一括払い（$49）
- **技術スタック**: Nuxt 3（フロント）+ FastAPI（バックエンド）+ Neon PostgreSQL + Tiptap（エディタ）
- **差別化ポイント**:
  - ページ数・ブロック数に制限なし（無料プランも）
  - Markdownエクスポートが常に無料
  - AIは「オプション」として別途課金（強制なし）
  - 起動・操作が爆速（Notionの重さへの不満解消）
- **個人開発可能性**: ◎ 2〜3週間でMVP可能。エディタはTiptap OSS活用で工数削減。

### アイデア2: **PingLog** — シンプルすぎる死活監視SaaS（UptimeRobot代替）

**背景**: UptimeRobotが2023年に無料枠を大幅縮小し、Betterstack等への移行が話題に。しかし移行先も機能過多で「URLを監視してSlack/メールに通知するだけでいい」というニーズが埋もれている。

- **想定ユーザー**: 個人開発者・小規模スタートアップのエンジニア
- **収益モデル**: 無料（5サイトまで）/ $4/月（50サイト）/ $12/月（無制限）
- **技術スタック**: FastAPI + APScheduler + Neon + Nuxt（ダッシュボード）+ Resend（メール通知）
- **差別化ポイント**:
  - 設定画面が1画面で完結（UXの複雑さへの対抗）
  - SSL証明書の有効期限チェックも同梱
  - 通知先はSlack / Discord / Email / Webhookに対応
  - ステータスページ公開機能（顧客向け障害情報ページ）も含む
- **個人開発可能性**: ◎ 監視ロジックはシンプル。1週間でMVP、2週間でβ公開が現実的。

### アイデア3: **FormSpark Local** — Googleフォーム離れユーザー向けフォームビルダー

**背景**: Googleフォームは回答データがGoogleに渡ることへのプライバシー懸念が高まっている（特にBtoB・医療・士業）。Typeformは高額すぎる（$25/月〜）。「GDPR準拠でシンプルなフォームが欲しい」という声が多い。

- **想定ユーザー**: 士業（税理士・社労士）、クリニック、中小企業の問い合わせフォーム担当
- **収益モデル**: $9/月（月500件まで）/ $19/月（無制限）+ 自社サーバーへのセルフホスト版（$199一括）
- **技術スタック**: Nuxt 3 + FastAPI + Neon + AWS S3互換ストレージ（ファイルアップロード対応）
- **差別化ポイント**:
  - データは自社DB or セルフホストのみ（Google/Metaへのデータ送信ゼロ）
  - 日本語UIファースト（Typeformは日本語UIが弱い）
  - フォーム回答のSlack/メール通知、CSVエクスポートがワンクリック
  - 条件分岐ロジック付きフォームが直感的に作れる
- **個人開発可能性**: ○ フォームビルダーのドラッグ&ドロップUIは工数がかかるが、vue-draggableなどで短縮可能。3〜4週間でMVP。

### アイデア4: **MeetSnap** — Calendlyの「1機能版」予約リンクツール

**背景**: CalendlyはSOC2・Salesforce連携など法人向けに進化しすぎ、個人フリーランサーが使うには$10/月でも割高感。「URLを共有して空き時間に予約してもらうだけ」という原点ニーズが残っている。

- **想定ユーザー**: フリーランスコンサルタント・コーチ・家庭教師・副業ワーカー
- **収益モデル**: 無料（月10件まで）/ $3/月（無制限）
- **技術スタック**: Nuxt 3 + FastAPI + Neon + Google Calendar API / iCal連携
- **差別化ポイント**:
  - 設定3ステップで予約リンク発行（Calendlyより圧倒的に速い）
  - Googleカレンダーとの双方向同期（無料から）
  - Zoomリンク自動生成（Google Meet / Zoom API連携）
  - 月$3という価格設定でポジション確立
- **個人開発可能性**: ◎ Google Calendar APIの認証が最大の工数。それ以外はシンプル。2週間でMVP可能。
