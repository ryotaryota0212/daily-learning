# 海外で流行っているが日本未上陸のサービス

作成日: 2026-07-05  
テーマ領域: 10. 海外で流行っているが日本未上陸のサービス

---

## 市場概要

- 日本のSaaS市場は2025年以降も年率15〜20%成長が続くが、海外の優れたプロダクトが日本語化されるまでに平均2〜3年のラグが存在する
- このラグを逆手に「海外で実証済みモデル × 日本語ローカライズ」で参入するのは個人開発者にとって有効な戦略
- 特にB2SMB（中小企業向け）SaaSは日本市場で未充足ニーズが大きい

### 注目している海外トレンド（参入余地あり）

| カテゴリ | 海外プロダクト例 | 日本での状況 |
|----------|----------------|-------------|
| パーソナルCRM | Clay, Folk | ほぼ未普及 |
| AI法務文書 | Harvey, Clio | 大企業向けのみ |
| 非同期動画レビュー | Loom（浸透済）, Bubbles | Bubbles系は未普及 |
| スケジューリング | Cal.com | Googleカレンダー依存で代替なし |
| マイクロSaaS決済 | Lemon Squeezy | 個人開発者に認知低 |

## 具体的なサービスアイデア

### 1. 日本版パーソナルCRM「えにし」

**概要**: 名刺・SNS・メール履歴を自動統合し、人脈管理をAIがサポートするCRM

**想定ユーザー**
- フリーランス・士業・営業職の個人
- 副業コンサルタント（月30〜100人の人脈管理）

**収益モデル**
- フリープラン: 連絡先100件まで
- Pro: 月980円（無制限 + AI提案機能）
- Team: 月2,980円/人

**技術スタック**
- Nuxt 3 + FastAPI + Neon（PostgreSQL）
- 名刺OCR: Google Vision API
- AI提案: Claude API（claude-haiku-4-5）

**差別化ポイント**
- 日本の名刺文化（PDF・画像名刺）への完全対応
- 「次に連絡すべき人」をAIが毎週通知
- 業種別テンプレート（税理士・コンサル・エンジニア）

**個人開発可能性**: ★★★★☆  
MVPは2〜3週間で構築可能。Clay($20/月)より安価な設定で差別化できる。

---

### 2. 非同期コードレビュー動画ツール「みせて」

**概要**: GitHubのPRに動画コメントを添付できる非同期レビューツール（Bubblesの日本版）

**想定ユーザー**
- リモートワークの開発チーム（5〜30人規模）
- フリーランスエンジニアとクライアント間のコードレビュー

**収益モデル**
- フリー: 動画5本/月まで（2分以内）
- Pro: 月1,500円/人（無制限 + GitHub連携 + 自動文字起こし）
- Team: 月800円/人（10人〜）

**技術スタック**
- Nuxt 3 + FastAPI + Neon
- 動画録画: MediaRecorder API（ブラウザネイティブ）
- 文字起こし: Whisper API
- ストレージ: Cloudflare R2

**差別化ポイント**
- GitHub PRとの1クリック連携
- 日本語自動文字起こし付き
- Slack通知との統合

**個人開発可能性**: ★★★★☆  
録画機能はブラウザAPIで実装可能。ストレージコストをR2で抑えられる。

---

### 3. 個人開発者向け決済ダッシュボード「売上くん」

**概要**: Stripe・App Store・Google Play・noteの売上を1画面で管理するダッシュボード（Lemon Squeezy的ポジション）

**想定ユーザー**
- 複数収益源を持つ個人開発者・クリエイター
- サブスク型SaaS運営の個人・小規模チーム

**収益モデル**
- 月額980円のフラット料金
- 年払いで2ヶ月分無料（9,800円/年）

**技術スタック**
- Nuxt 3 + FastAPI + Neon
- Stripe API・App Store Connect API・Google Play API統合
- グラフ: Chart.js or Recharts

**差別化ポイント**
- 日本の確定申告（freee連携）を意識した経費区分タグ
- 円換算レートをリアルタイム表示
- 月次レポートをPDFで自動生成

**個人開発可能性**: ★★★★★  
API連携が主体で複雑なAI機能不要。1週間でMVPを出せる。

## 実現可能性の評価

| サービス | 開発難易度 | 市場規模 | 競合 | 総合 |
|---------|-----------|---------|------|------|
| えにし（CRM） | 中 | 中〜大 | 弱 | A |
| みせて（動画レビュー） | 中 | 中 | 弱 | A |
| 売上くん（決済ダッシュボード） | 低 | 小〜中 | 無 | A+ |

**共通の成功要因**
- 日本語ローカライズの徹底（英語UIでは刺さらない）
- 既存の日本人が使うツール（freee・Slack・GitHub）との連携
- 月1,000円以下の価格設定（導入摩擦を下げる）

**個人開発者向け優先度**: 売上くん > えにし > みせて
